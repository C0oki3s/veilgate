{{/* ── DETECTOR ─────────────────────────────────────────────────── */}}
Detector
Score thresholds, detection window, honeypot paths, and IP trust lists.
Requires restart
Score Thresholds
Score ≥ this → serve JS/PoW challenge. Default: 40.
Score ≥ this → serve shadow app. Must be ≥ challenge threshold. Default: 70.
Rolling window for per-client score accumulation. 60–90 s for busy sites; 120–300 s for low-volume APIs.
0–29 low → 30–59 medium → 60–79 high → 80–100 critical
Honeypot Paths
One path per line. Requests to these paths add +50 pts (first hit) or +80 pts (repeat). Never list paths your real app serves. Leave empty to use built-in defaults.
Trust Lists
One IP per line. These clients bypass scoring entirely. Use for CI runners, monitoring, internal services.
CIDRs whose X-Forwarded-For header is respected. Empty = always use direct RemoteAddr (stops XFF injection). Required when a reverse proxy sits in front of VeilGate.
When traffic passes through a CDN or reverse proxy, VeilGate can read the TLS fingerprint and real client IP from CDN-injected headers instead of computing them from the raw connection. Only honoured when the TCP connection arrives from a Trusted Proxy CIDR above — direct-connection forgery is blocked. CDN fingerprinting guide →

Challenge
JavaScript proof-of-work parameters. Secret must be set before using challenge or tarpit mode.
Requires restart
HMAC secret used to sign challenge tokens. Generate with openssl rand -hex 32. Use ${VEILGATE_SECRET} to read from environment. The default is a placeholder anyone can forge. {{if and $c (eq $c.Challenge.Secret "change-me-in-production-or-set-VEILGATE_SECRET")}}
Secret is still set to the insecure default. Set a real secret before enabling challenge or tarpit mode.
{{end}}
Number of leading hex zeros required. Clamped to 1–4 at runtime.
How long an issued challenge token is valid. SDK renews 60 s before expiry. Default: 30 min.
Hard ceiling on issued TTL. Requested TTL is silently clamped to this value. Default: 60 min.
{{/* ── TARPIT ───────────────────────────────────────────────────── */}}
Tarpit
Latency, body size, and response-cache caps for the shadow-app deception layer.
Requires restart
Response Timing
Lower bound for artificial delay per tarpit response. Default: 500 ms.
Upper bound. LLM-agent defense: use 8000–30000 ms to burn tokens. Default: 3000 ms.
Hard cap on rendered tarpit response body. Protects VeilGate's outbound bandwidth. Default: 102400 (100 KiB).
Response Cache
Per-client (IP, path) response cache lifetime. Agents re-fetching the same path within this window get byte-identical responses. Default: 30 min.
Maximum cached (clientID, path) entries. New entries are dropped once the cap is reached. Default: 50000.
Tarpit content (templates, fake data, injection payloads) is configured in rule files: templates.yaml, payloads.yaml, injection_strategy.yaml.
{{/* ── TLS ──────────────────────────────────────────────────────── */}}
TLS
Enable to get JA3/JA4 TLS fingerprinting as an additional detection signal.
Requires restart
When enabled, VeilGate terminates TLS itself so it can read the ClientHello for JA3/JA4 fingerprinting. Requires a certificate and key file.
Path to PEM-encoded TLS certificate. Generate self-signed: openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes
Path to PEM-encoded private key.
{{/* ── PERSISTENCE ──────────────────────────────────────────────── */}}
Persistence
SQLite event store (feeds ML classifier) and JSONL capture firehose (for offline research).
Requires restart
{{/* Persist subsection */}}
SQLite Event Store persist:
Required for online ML classifier and veilgate forget --ip. Production deployments should enable this.
Path to the SQLite file. Recommended: /var/lib/veilgate/events.db.
Directory for rotated events-*.csv.gz archives. Empty = trim without archiving.
Trim goroutine runs every 6 h. 0 disables trimming. Default: 30.
Batch-commit interval. Raise to 2000–5000 ms for very high RPS. Default: 1000.
Event-write channel buffer. When full, events are dropped rather than blocking the proxy. Default: 4096.
SQLite page cache size. Default: 65536 (64 MiB). Raise to 262144–524288 for read-heavy dashboards.
{{/* Capture subsection */}}
JSONL Capture Firehose capture:
Writes one JSONL line per request (score, decision, signals). Use for ML research. Default: off. Consider privacy implications before enabling in production.
JSONL file path. Recommended: /var/lib/veilgate/requests.jsonl.
How often the janitor sweeps rotated files. Go duration: 30m, 1h, 6h. Default: 1h when retention is set.
Rotate file at this size. Default: 100 MB.
Delete rotated files older than this. 0 = never delete. Common: 168 (7 days).
POSIX octal permissions. 0o600 = owner read/write only. Use 0o644 only if a log-shipping agent needs read access.
Scrub rules (capture.scrub) for PII redaction are only editable in the tab — they use regex patterns not suited to a form field.
{{/* ── OBSERVABILITY ────────────────────────────────────────────── */}}
Observability
Prometheus pull endpoint and OpenTelemetry push (traces, logs, metrics).
Requires restart
{{/* Metrics subsection */}}
Prometheus Endpoint metrics:
When checked, the /metrics pull endpoint is turned off entirely. OTLP push (below) is unaffected.
Bind to loopback in production. Use :9090 only if Prometheus scrapes from a different host.
Bearer token required on /api/* endpoints. Leave empty to disable auth on the metrics port.
{{/* OTLP subsection */}}
OTLP Transport telemetry.otlp:
Base URL of OTLP/HTTP receiver. Do not add a path suffix — VeilGate appends /v1/traces, /v1/logs, /v1/metrics automatically. Empty = disable OTLP.
Enable only for http:// endpoints (local collector, Docker Compose, dev). Never use in production.
One header-name: value per line. Common keys: signoz-access-token, x-honeycomb-team, authorization, dd-api-key.
{{/* Traces subsection */}}
Traces telemetry.traces:
Suppress trace export even when an OTLP endpoint is configured.
0.01 = 1 % (default). Use 1.0 in dev. Keep ≤ 0.05 on high-traffic prod to avoid overwhelming the collector.
{{/* Logs + Metrics Push */}}
Logs & Metrics Push telemetry.logs: / telemetry.metrics_push:
Every zerolog line is forwarded as a structured OTLP LogRecord. Stderr output is always written regardless.
Runs alongside the Prometheus pull endpoint — both can be active. Same counters and histograms, pushed on an interval.
Go duration: 30s, 1m, 5m, 1h. Default: 30s.
{{/* ── VERIFIERS ────────────────────────────────────────────────── */}}
Verifiers
Alternate authenticator chain for non-browser clients (server-to-server, mobile, partner integrations). Accepted requests skip challenge but not tarpit.
Requires restart
{{/* HMAC */}}
HMAC Request Signatures verifiers.hmac:
Stripe-style HMAC-SHA256 request signatures. Covers timestamp + method + path + body hash — prevents replay and tampering.
Header carrying t=<unix-ts>,v1=<hex-sha256>. Default: X-Veilgate-Signature.
Header naming which client secret to look up. Default: X-Veilgate-Client.
±window around now within which the timestamp must fall. Default: 300 (5 min).
Body bytes hashed for the signature. Cap against memory exhaustion. Default: 1048576 (1 MiB).
Directory of <client-name>.secret files. Hot-reloaded on mtime change — rotate secrets without restarting.
{{/* Bearer */}}
Bearer Token verifiers.bearer:
Opaque static tokens (GitHub PAT / Stripe API key model). Compared via SHA-256. No per-request replay protection — rely on TLS and rotate on compromise.
Request header carrying the credential. Default: Authorization.
Prefix stripped before token lookup. Auto-set to Bearer when header is Authorization. Set to "" for raw-token headers.
One .token file per client. Hot-reloaded on directory mtime change.
Cookie and Header verifiers (verifiers.cookies:, verifiers.headers:) support JWT and callout validation. These are lists of structured objects and are only editable in the . Changes made here to HMAC and Bearer do not affect existing cookie/header verifier entries.
